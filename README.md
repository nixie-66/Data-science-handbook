# 🐍 Python Data Science Handbook - Study Notes & Practice

This repository contains my personal Jupyter Notebooks, hands-on code examples, and summarized notes as I work through **"Python Data Science Handbook"** by *Jake VanderPlas*.

---

##  Topics Covered

*  **NumPy:** Fast multidimensional array operations, ufuncs, and broadcasting.
*  **Pandas:** Data manipulation, DataFrames, indexing, and missing data handling.
*  **Matplotlib & Seaborn:** Data visualization, plotting techniques, and custom styles.
*  **Scikit-Learn:** Machine Learning algorithms, feature engineering, and model validation.

* Document my learning journey in Data Science.
* Practice vectorized programming and NumPy/Pandas workflows.
* Keep clean, well-annotated Python notebooks for future reference.
